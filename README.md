# 🚀 Physics Calculator

A simple physics calculator for self-study - Orbital, gravity, escape velocity and more. 
Built with Python & Flask.

🔗 **Live Demo:** https://physics-calculator.onrender.com

## ✨ Features
- 🌍 Orbital Velocity Calculator
- 🌌 Escape Velocity Calculator
- ⚖️ Gravitational Force Calculator
- 🚀 Velocity & more physics formulas
- Simple and clean UI for students

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render
